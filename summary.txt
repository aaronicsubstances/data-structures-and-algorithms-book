/** CHAPTER 10 **/
// Array list and linked list

Array list: enough for generic list. achieves superior time performance of O(1) due to amortisation 
of add/remove operations which once in a while require allocating existing array to another
memory location with double or half the capacity.

Linked list: superior memory management, but O(n) for operations make it inferior for use
as a random access generic list.
singly-linked: enough for stacks and queues
doubly-linked: used for deques and circular lists

/** CHAPTER 11 **/
Linked list, sorted: used for bags/multisets and sets with comparable elements
skip lists: best possible use of lists for implementing maps, if not
using hashing or binary trees
Hashtables: better performance for maps and sets
